# 缓存存储与请求分配分离

讨论已确定采用共同缓存父类与不同存储子类：子类负责存储大小、布局、初始化和层视图；请求的申请、扩容、释放及编号归属由独立管理逻辑复用。当前实现目标是 Qwen3，后续通过新增子类扩展到 DeepSeek-V4.1-Flash 等缓存形态。

存储 buffer 由具体子类申请，父类规定公共接口，不统一实现显存申请。这样模型特有的物理组织和初始化留在同一子类中；各子类遵循已确定的 page_first 历史与统一状态槽位约定。

不采用每种模型各自实现完整请求缓存管理器的方案，以减少请求生命周期和编号管理逻辑的重复。具体类名、方法签名与物理布局尚未确定；历史块的分配单位见 ADR 0002。本决定不代表实现已经完成。Backend 兼容不属于本轮讨论范围。
