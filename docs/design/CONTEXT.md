# inferX 缓存领域术语

本术语表记录缓存设计讨论中已经确定的概念。

## Language

**请求（Request）**：一次独立的生成任务，其推理历史跨多个计算步骤保留。

**缓存块（Cache Block）**：为一个请求的一段固定长度的原始 token 位置区间预留的历史缓存单位，涵盖该区间对应的各层及各类历史数据。压缩历史在该区间内的记录数可以不同。

**块表（Block Table）**：按请求内逻辑区间顺序排列的物理缓存块编号表；同一请求的各层及各类历史共用这张表。

**前缀复用（Prefix Reuse）**：不同请求复用相同前缀对应的已计算缓存内容。它与同一请求内各类历史共用块编号是不同概念。

**请求状态（Request State）**：为继续处理请求而跨计算步骤保留的窗口内容和过程状态，例如滑动窗口缓存与未完成压缩组的状态；其容量不随完整历史长度持续增长。

**状态槽位（State Slot）**：一个请求所需的请求状态的统一存储单位，在该请求存活期间保留。

**层缓存视图（Layer Cache View）**：某一层计算可访问的缓存区域集合；不同层可以引用相同的共享历史区域。
